# Сопоставимые муниципалитеты

Решение для онлайн-конкурса СберИндекса 2026, направление «Кластеризация».

Для каждого из 2 068 муниципалитетов России найдены 15 экономически сопоставимых по данным СберИндекса о тратах жителей и по показателям Росстата. Карточка муниципалитета отвечает на три вопроса: где его потенциал (место среди сопоставимых по ключевым показателям), у кого учиться (сопоставимые с наибольшим ростом трат и чем они отличаются) и не уходит ли он от своего типа. Под продуктом — двухуровневая типология на атрибутированной сети муниципалитетов, построенная алгоритмом KEFRiN.

- **Лендинг:** `site/index.html` — один файл, открывается с диска и публикуется через GitHub Pages.
- **Методологический отчёт:** `report/methodology.md`.
- **Датасет:** `outputs/dataset/` — таблица сопоставимых МО и JSON-карточка на каждый МО, ключ `territory_id` справочника СберИндекса.

## Результаты

- **Сопоставимые МО дают другой вывод, чем свой регион.** Вывод «траты жителя выше или ниже медианы» меняется у 38% МО, если сравнивать с 15 сопоставимыми, а не со своим регионом. Пример: Чебоксары тратят на 77% больше медианы Чувашии, но среди 16 сопоставимых городов — на 15-м месте.
- **Пять типов локальной экономики:** стареющая глубинка (627 МО), удалённая периферия (554), города и промышленные центры (474), ресурсные территории (154), столицы и ближнее Подмосковье (259). Устойчивость на подвыборках — ARI 0,945 в медиане; независимый индекс мобильности СберИндекса различает типы (η² = 0,64).
- **Выбор числа типов проверен на синтетике.** На 84 атрибутированных сетях с известным ответом (генератор Шалилеха из репозитория KEFRiN) S_Dbw, AVI и AVU непригодны для выбора K; правило Борда по двум равновесным блокам индексов (признаки и сеть) точнее голосования. Нулевая модель подтверждает, что кластерная структура есть.
- **KEFRiN, ξ = 2.** На синтетике — без провалов при слабых признаках и при зашумлённой сети; на реальных данных совпадает с k-средних по признаковым индексам и превосходит его по сетевым (10 запусков на метод).
- **Правило ребра — слияние структуры трат и дорожной близости:** самые однородные соседи и по 30 признакам, и по показателям Росстата, которые в ребро не входят.
- **Динамика 2024 года без общестранового сдвига:** тип сменили 67 МО; флаг расхождения — у 167.
- **Описания типов — интервальные узорные структуры** с проверкой на отложенной половине МО (точность 0,63–1,00).
- **Проверка флага расхождения новостями — связь не обнаружена.** 1 875 заголовков 2024 года по 256 МО размечены открытой моделью GigaChat 3.1 на GPU Kaggle: экономические события у 34% МО с флагом и у 43% МО контрольной группы того же типа (p = 0,09). У типичного МО 2–3 заголовка за год; следующий шаг — местные источники новостей.

## Запуск

Нужны [uv](https://docs.astral.sh/uv/) и Node.js (только для шага `geo`: упрощение границ через `npx mapshaper`).

```bash
uv sync
uv run mopeers all          # все шаги по порядку
uv run mopeers --help       # список шагов; любой шаг запускается отдельно: uv run mopeers typology
```

Шаг `download` скачивает исходные данные из официальных источников и проверяет SHA-256 пакета Data Sense. Шаг `data` скачивает из Базы данных показателей муниципальных образований Росстата только нужные показатели и только за 2022–2024 годы (каталог «Точно», чтение отдельных файлов из архивов по HTTP Range). Код алгоритмов жюри (KEFRiN, генератор синтетики, метрики Pattern) скачивается с зафиксированных коммитов GitHub в `third_party/` и не изменяется.

Полный прогон после скачивания данных занимает около 35 минут на ноутбуке (12 ядер, без GPU). Прогон с нуля в чистой копии репозитория дал побайтно те же 2 106 из 2 107 файлов `outputs/`; отличается только упрощённая карта границ `outputs/geo/mo.topojson` (5 байт).

## Гиперпараметры

Все параметры — в `configs/base.yaml`: окна признаков, правила рёбер и k соседей, методы и перебор K, вес сети ξ, параметры типологии, синтетики, интерпретации и продукта. Названия и описания типов — `configs/types.yaml`.

## Структура

| Путь | Содержимое |
|---|---|
| `src/mopeers/` | конвейер: `download`, `data`, `rosstat`, `features`, `network`, `cluster`, `synth`, `typology`, `dynamics`, `interpret`, `product`, `news`, `geo`, `site` |
| `kaggle/` | ядро Kaggle для новостного слоя (GigaChat 3.1, GPU) |
| `configs/` | гиперпараметры и описания типов |
| `outputs/network/` | сравнение правил рёбер |
| `outputs/cluster/` | сетка ICVI, синтетика, нулевая модель, перебор ξ, методы по сидам |
| `outputs/typology/` | типы, выбор K, устойчивость |
| `outputs/dynamics/` | типы по окнам, переходы, флаг расхождения |
| `outputs/interpret/` | профили типов, интервальные описания, пороговые правила, сверка с категориями, мобильность |
| `outputs/dataset/` | продукт: `mo_peers.csv`, `api/<territory_id>.json` |
| `site/` | шаблон и собранный лендинг |
| `report/` | методологический отчёт |

- СберИндекс: потребительские безналичные расходы на уровне МО, индекс доступности рынков, расстояния между МО, справочник и границы МО, индекс мобильности; пакет хакатона Data Sense 2025 (население, миграция, зарплата по данным Росстата). Лицензия CC BY-SA 4.0.
